Lanternkeeper — a 2D arena-defense game. You are a wisp guarding the last lantern in a dark valley: fly with WASD or the arrow keys, aim with the mouse, and shoot bolts of light at the shadows drifting in from the night. Every shadow that reaches the lantern burns one of its flames. Chain kills for a combo multiplier, catch falling power-ups, and body-block a shadow to purify it for half points. Waves grow harder — darters zigzag, brutes take three hits, splitters burst into two. How many waves can you hold?

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network: the game is plain static files under `game/`, with synthesized WebAudio sound effects and no assets to download.
